# Desafio de Conversão de Temperatura 

Projeto desenvolvido durante o curso da Alura para praticar conceitos fundamentais de Java.

##  Funcionalidades
  Converti uma temperatura de Celsius para Fahrenheit.
  Utilizei a fórmula: `(celsius * 1.8) + 32`.
  Realizei o Casting de tipos para exibir o valor em Fahrenheit como um número inteiro.

##  Tecnologias
 Java (JDK 17 ou superior).
 IntelliJ IDEA.

##  Exemplo de Saída
O programa exibe no console a temperatura formatada e sua versão inteira.
